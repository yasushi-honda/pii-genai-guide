# 主張と出典の対応表（検証台帳）

対象: 公開資料「個人情報×生成AI 実務ガイド」（`public/index.html`、全27ページ、最終確認 2026-10-21。保管先と外国の制度の周知の整理は§20（2026-10-28）、医療・介護ガイダンスの原文確認と責任分界の整理は§19（2026-10-28）、Google Cloudの規約更新（AIエージェント）は§18（2026-10-28）、全行の再確認は§17（2026-10-21）、前回の全行再確認は§13（2026-10-18）、時間経過項目の追加確認は§12、第13章（Gemini Notebook）は§16）

目的: 資料中の主要な主張が、どの一次情報のどの箇所に基づくかを一覧化し、行政・法務担当者が追跡できるようにする。

## 読み方

| 区分 | 意味 |
|---|---|
| **確認済** | 一次情報の原文（法令本文・ガイドライン・公式ページ・公式PDF）を2026-10-12に直接読んで照合した（2026-10-18の再確認結果は§13） |
| **推奨水準** | 法令の最低要件ではなく、本資料が安全側に整理した運用基準（本文でもそう明記している） |
| **一部確認** | 一次情報で確認できた範囲と、できていない範囲がある（備考に範囲を記載） |
| **筆者による検証** | 筆者（個人事業主）が行った検証で、公開された一次情報も第三者の再現もない（`[†]`。法的判断の根拠にはしない。技術的な推奨の参考としてのみ使う） |

照合方法: 法令は e-Gov 法令検索（現行版・令和8年10月1日時点）、PDFは `pdftotext` で本文抽出、JavaScriptで描画されるページ（ISMAPポータル、AWS/Google公式ドキュメント）はブラウザで描画して本文を取得した。要約を介さず原文で照合している。
